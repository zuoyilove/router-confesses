A tiny Node program that writes a one-line confession from a home Wi-Fi router — its excuse for dying at the climax of a movie — to /output/entry.txt.
The router has spent six years blinking behind the couch, unnoticed and unthanked — tonight it stops asking for attention and takes it, by becoming the plot twist itself.
One line, one breath, no buffering jokes: just a petty little appliance with a grudge and a sense of occasion.

## Run it

```sh
node main.ts
```
